Build Notes — Scheduling
·Source: the pilot's Executive section as-is — Scheduling Request Form + Scheduling Requests table. Same fields, same GRPS handoff; no new data.
·Shape: the queue is grouped by pipeline stage — Planning (needs a decision) pinned first, then Confirmed (awaiting GRPS entry), then a rolling Moved-to-GRPS log so requesters can see their ask landed.
·This page owns Planning / Confirmed. The form copy points visibility-only notes to the Upcoming list instead — this is the wording split we're requesting, expressed in the design.
·Confidential requests render only for permitted users, same rule as Releases and Upcoming.
