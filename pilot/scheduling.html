Build Notes — Scheduling
·Data: real records from the Scheduling Request tracker, week of Aug 3 (as of Aug 10) — this page now shows the live queue, not sample data.
·Source: the pilot's Executive section as-is — Scheduling Request Form + Scheduling Requests table. Same fields, same GRPS handoff; no new data.
·Shape: the queue is grouped by pipeline stage — Planning (needs a decision) pinned first, then Approved (date locked, awaiting GRPS entry), then a rolling Moved-to-GRPS log so requesters can see their ask landed.
·This page owns Planning / Approved. The form copy points visibility-only notes to the Upcoming list instead — this is the wording split we're requesting, expressed in the design.
·Interactive: click any request to expand it — asset checklist (clearance / master / art), dates, scheduler, and exactly what’s still missing, straight from the Release Grid.
·Confidential requests render only for permitted users, same rule as Releases and Upcoming.
