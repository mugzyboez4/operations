Build notes — how this maps to the pilot

→Slices: the Releases.Type formula (off CONFIG_NAME from Products) drives the rows — extending it to physical / video / ancillary is the same formula change already proposed on the artist page.
→Rollups: big ancillary batches (lyric-video runs, live sessions) collapse to one tile per artist with a count — click expands the full list. Empty categories collapse to one quiet line.
→Indicators: the Runway legend (Focus, International, Instant Grat, Atmos, Delivered, Confidential…) carries over as chips — sourced from the same product flags. Confidential releases render for permitted users only, matching Releases.Status = Confidential.
→My Artists scoping uses the same Directory assignment the pilot already has.
