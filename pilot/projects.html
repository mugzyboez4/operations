Build Notes — Projects
·Source: the pilot's Projects table as-is — Title · Project Type · Status · Assignee (→ Contacts) · Due Date · linked Release/Artist. No new fields.
·Shape: grouped by Status with In Review pinned first — that's where things stall. Stat strip up top gives the queue's shape at a glance; Type filter chips narrow the board.
·Auto-created tickets (the five per scheduled release) land in Not Started with an Auto chip so teams can tell them from hand-raised requests. Second-tier types (Music Video, Lyric Video, etc.) appear only after someone confirms the prompt.
·My Artists scoping uses the same Directory user assignment as everywhere else in the pilot.
