Build Notes — DSP Pitches
·Source: the pilot's Streaming: DSP Pitches view as-is — Name · Release Date · Release Week grouping · Spotify URI · Apple ID · Pitch, with the existing Future / All toggle. No new tables.
·Pitch status is a formula, not a new workflow: empty Pitch field = Missing, filled = Drafted, submitted flag = Submitted. Missing pitches sort to the top of each week so the gap is impossible to miss.
·Editor pane: click a release, write the pitch in place — same record, same fields the current detail pane shows, just side-by-side with the queue instead of replacing it.
·My Artists filter uses the same Directory user assignment as everywhere else in the pilot.
