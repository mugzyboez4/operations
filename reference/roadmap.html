Before this goes in front of anyone

The board needs a status pass

These are data-quality problems, not delivery problems, and they are the difference between a board that reads as stalled and one that reads as blocked on access.

  • 43 of 45 items have no owner

    The single cheapest fix before anyone sees this. Unowned items read as unstarted regardless of reality.

  • 3 of 45 done reads as 7%

    It isn't true. The budget sign-off suite is live on /budget/, the pitch-deck system is live on the hub, and neither appears here. The board undersells you.

    The Airtable proxy layer is down site-wide — phase-1 returns 500 on a missing token, priorities returns a 403 from Airtable. Items written as “live via /api/… proxy” are not live right now. Blocked is the closest available status.

  • Two dates have passed

    “Scott July 1 — Production Meeting ownership transition” is six weeks overdue, and “Tarek arrival — roles defined” reads stale given he has been in the room since March. Both need a status pass, not a guess.

    It says 16 ideas, Tier 3 = 2, blocked = 4. The register actually holds 17, Tier 3 = 3, blocked = 5 — ID 17 was added after the summary was written. Fix before presenting.
