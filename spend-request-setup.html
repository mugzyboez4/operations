Spend Requests — setup

Campaign Ops · RCA Records

Three files

Spend Requests.xlsxThe table every submission lands in. Tabs: Read me, Requests, Lists, Roster.
spend-request.htmlThe form. Same look as budget-approvals.html on the ops site.
This pageFlow and Teams steps.

1 · Put the workbook in SharePoint

Upload Spend Requests.xlsx to USA RCA Records-Ops – Working Docs → 5 - Tools & Builds. Open it once in Excel Online. Delete row 2 of Requests when real requests start landing.

Table name is SpendRequests. The flow points at that name — renaming it breaks the write.

2 · Flow A — write a row

Power Automate → Create → Instant cloud flow → skip trigger → search When an HTTP request is received.

TriggerWhen an HTTP request is received. Schema below. Who can trigger: Anyone.
Step 2Excel Online (Business) → Add a row into a table. Location: SharePoint site. Document library: Documents. File: Spend Requests.xlsx. Table: SpendRequests.
Step 3Response. Status 200. Headers Access-Control-Allow-Origin: *. Body {"ok":true}.

Request ID: set the field to concat('SR-', substring(utcNow(), 0, 19)), or leave it blank and number by hand.

Save, then copy the trigger's HTTP POST URL into CONFIG.POST_URL at the top of spend-request.html.

3 · Flow B — read the sheet back

Same trigger type, second flow. Step 2: Excel Online → List rows present in a table, same file and table. Step 3: Response, status 200, header Access-Control-Allow-Origin: *, body @{body('List_rows_present_in_a_table')?['value']}.

Copy that flow's URL into CONFIG.FEED_URL. Until it's set, the table on the right reads from the browser only.

4 · Host the form and add it to Teams

  1. Push spend-request.html to the mugzyboez4/operations repo — same route as the ops site.
  2. Set CONFIG.WORKBOOK_URL to the SharePoint link so "Open the sheet" works.
  3. Teams → the channel → + → Website → paste the page URL → name it Spend requests.
  4. Second tab: Excel → point at the workbook, for anyone updating Status, PO # or Invoice #.
